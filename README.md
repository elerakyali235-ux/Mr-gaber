# منصة مستر محمد جابر | منصة اللغة العربية

منصة تعليمية شاملة للغة العربية للمرحلتين الإعدادية والثانوية

## 🚀 التثبيت السريع

### الطريقة الأولى: سكريبت تلقائي (الأسهل)

#### على ويندوز:
1. تأكد من تثبيت [Node.js](https://nodejs.org/) (اختر نسخة LTS)
2. اضغط مرتين على ملف `setup.bat`
3. انتظر حتى ينتهي التثبيت
4. شغّل التطبيق بالأمر: `npm run dev`
5. افتح المتصفح على: `http://localhost:3000`

#### على ماك أو لينكس:
1. تأكد من تثبيت [Node.js](https://nodejs.org/) (اختر نسخة LTS)
2. افتح Terminal في مجلد المشروع
3. شغّل الأمر: `bash setup.sh`
4. شغّل التطبيق بالأمر: `npm run dev`
5. افتح المتصفح على: `http://localhost:3000`

### الطريقة الثانية: تثبيت يدوي

1. ثبّت [Node.js](https://nodejs.org/) (اختر نسخة LTS - الإصدار المستقر)
2. افتح Terminal أو Command Prompt في مجلد المشروع
3. شغّل الأوامر التالية بالترتيب:

```bash
# تثبيت المكتبات
npm install

# إعداد قاعدة البيانات
npx prisma generate
npx prisma db push

# تشغيل التطبيق
npm run dev
```

4. افتح المتصفح على: `http://localhost:3000`

## ❓ حل المشاكل الشائعة

### المشكلة: "npm" غير معروف
**الحل:** تأكد من تثبيت Node.js من [الموقع الرسمي](https://nodejs.org/)

### المشكلة: خطأ في تثبيت المكتبات
**الحل:** شغّل الأمر التالي ثم حاول مرة أخرى:
```bash
npm cache clean --force
npm install
```

### المشكلة: الصفحة لا تفتح
**الحل:** تأكد أن التطبيق يعمل (ستظهر رسالة "Ready" في Terminal) ثم افتح `http://localhost:3000`

### المشكلة: خطأ في قاعدة البيانات
**الحل:** شغّل الأوامر التالية:
```bash
npx prisma generate
npx prisma db push
```
