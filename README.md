## ✨ المميزات

### 👨‍🎓 للطلاب
- 📚 مشاهدة المحاضرات والفيديوهات مع **علامة مائية ثلاثية** باسم الطالب
- 📝 أداء الامتحانات التفاعلية (اختيار من متعدد) مع نتيجة فورية
- 📋 تسليم الواجبات مع رفع ملفات (صور/PDF)
- 💰 نظام الاشتراك والدفع (فودافون كاش)
- 🛟 دعم نفسي بالذكاء الاصطناعي
- 📱 إشعارات واتساب لأولياء الأمور
- 🔔 نظام إشعارات
- 👤 إدارة الحساب الشخصي

### 👨‍💼 للمشرف
- 📊 لوحة تحكم شاملة مع إحصائيات
- 👥 إدارة الطلاب ومتابعة الاشتراكات
- 📖 إدارة المحاضرات والمحتوى (فيديو/PDF/روابط)
- 📝 إنشاء الامتحانات التفاعلية
- 📋 إنشاء الواجبات ومتابعة التسليمات
- 💰 متابعة المدفوعات (تأكيد/رفض)
- 🛟 إدارة حالات الدعم النفسي
- 📱 إعدادات تقارير واتساب لأولياء الأمور
- 🔒 سجل مشاهدات الفيديوهات مع تتبع IP
- ⚠️ تنبيهات IP مشبوهة (حماية المحتوى من المشاركة)

## 🛡️ نظام حماية المحتوى

| الطبقة | الوصف |
|--------|-------|
| 🔴 علامة مائية متحركة | تتنقل على الفيديو كل 8 ثوانٍ (اسم الطالب + رقمه) |
| 🟡 علامة مائية ثابتة | في الزاوية السفلية بشكل دائم |
| 🟢 علامة مائية مائلة | نص مكرر على كامل الفيديو بشفافية منخفضة |
| 📍 تتبع IP | تسجيل عنوان IP عند كل مشاهدة |
| ⚠️ تنبيه IP مشبوه | عند مشاهدة أكثر من طالب من نفس IP |
| 🚫 منع التحميل | إخفاء زر التحميل + منع النقر اليمين + منع PiP |

## 🚀 التثبيت والتشغيل

### المتطلبات
- **Node.js** الإصدار 18 أو أحدث
- **npm** أو **bun**

### الطريقة الأولى: سكريبت تلقائي

#### ويندوز:
```cmd
setup.bat
npm run dev
```

#### ماك/لينكس:
```bash
bash setup.sh
npm run dev
```

### الطريقة الثانية: تثبيت يدوي

```bash
# 1. تثبيت المكتبات
npm install

# 2. إعداد قاعدة البيانات
npx prisma generate
npx prisma db push

# 3. نسخ ملف الإعدادات
cp .env.example .env

# 4. تشغيل التطبيق
npm run dev
```

5. افتح المتصفح على: `http://localhost:3000`

## ❓ حل المشاكل الشائعة

### المشكلة: "npm" غير معروف
**الحل:** تأكد من تثبيت Node.js من [الموقع الرسمي](https://nodejs.org/)

### المشكلة: خطأ في تثبيت المكتبات
```bash
npm cache clean --force
npm install
```

### المشكلة: خطأ في قاعدة البيانات
```bash
npx prisma generate
npx prisma db push
```

### المشكلة: الصفحة لا تفتح
تأكد أن التطبيق يعمل (ستظهر رسالة "Ready" في Terminal) ثم افتح `http://localhost:3000`
